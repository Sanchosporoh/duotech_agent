Схема показывает смысловые передачи данных, а не все вызовы функций. Общий снимок доступен последующим этапам; дублирующие стрелки не нанесены. Хранилища результатов указаны в подписях блоков. Обработка комментария инженера синхронная; пунктир обозначает обратный поток, а не фоновую очередь. Штатная легенда Archify на английском. Проект не содержит отдельной технической очереди или сервиса сообщений.

Исследованные альтернативы: Structurizr (несколько архитектурных представлений из одной модели), D2 (схемы из текста с несколькими досками). Для текущего MVP выбран уже доступный Archify Data Flow, чтобы не добавлять инфраструктуру.
