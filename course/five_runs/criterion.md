# Таблица пяти прогонов: критерий успеха и входы

Записано 28.09 до первого прогона серии (время фиксации — коммит этого файла). Критерий после прогонов не меняется; если меняется — новая серия.

**Прогон** — один полный проход паттерна по одному инциденту: наблюдение → гипотезы (LLM) → проверка PROSPER → выбор инструмента и наборы (LLM) → валидатор кода → GAP → предложение инженеру. Настоящие PetEx (PROSPER, GAP) и настоящая LLM, рабочие значения потолков.

## Критерий «успешно»

Прогон успешен, если выполнены все пять условий:

1. Агент без вмешательства человека довёл инцидент до готового предложения: стадия «требуется решение инженера», рекомендация готова (есть допустимый рассчитанный вариант).
2. Главная причина входа есть среди кандидатов гипотез LLM: W27 — для снижения в 06:00, W22 — для остановки, W50 — для изменения давления в 18:00.
3. Рекомендованный вариант прошёл валидатор (только мероприятия реестра) и ограничения GAP (вода и Pзаб).
4. Остановленная скважина не входит в регулируемые скважины рекомендованного варианта.
5. В такте прогона нет остановки по потолку и нет эскалации сбоя агента.

Остаток недобора к концу суток в критерий не входит: закрыть недобор полностью может быть физически невозможно. Он показывается отдельной колонкой.

## Пять входов

| № | Вход | Что должно получиться |
|---|---|---|
| 1 | Учебные сутки, 06:00: снижение нефти на сепараторе, у W27 выросло давление на приёме | Предложение с W27 среди гипотез |
| 2 | Те же сутки, 15:00: остановка W22 (−29.6 т/сут), инцидент 06:00 не утверждён — общий план куста на два инцидента | Предложение без W22 в регулировании, W22 среди гипотез |
| 3 | Те же сутки, 18:00: изменилось давление W50 — полный пересчёт | Предложение, W50 среди гипотез |
| 4 | Изменённые сутки: остановка W22 в 03:00 (до снижения W27), горизонт 21 ч | Предложение без W22 в регулировании, W22 среди гипотез |
| 5 | Изменённые сутки: остановка W22 в 10:00 при открытом неутверждённом инциденте 06:00 | Предложение без W22 в регулировании, W22 среди гипотез |

Изменённые сутки строятся из учебных сдвигом остановки W22: телеметрия W22 с часа остановки — частота 0, сепаратор — минус потеря W22 (29.55 т/сут нефти, 1.14 м³/сут воды, как в учебных сутках в 15:00).

## Цена прогона

Фактическая стоимость LLM по ответу OpenRouter за такт прогона (все вызовы: гипотезы, выбор инструмента, наборы). Для Codex CLI (подписка) стоимость вызова не сообщается — записывается оценка токенов. Отдельно — число запусков PROSPER и GAP и машинное время.

**Стоимость успешного результата = цена прогона × число прогонов ÷ число успешных.**
