# Скринкаст v2 (доработка вехи 2 + кадры вех 3–4): сценарий до 5 минут

Что должно быть видно — по замечаниям ревьюера:

| Позиция | Кадр |
|---|---|
| **Гейт** | утверждение → задача появляется в Битрикс24 во втором окне |
| 3.1 | агент запущен командой-расписанием и сам идёт по часам, без кнопки |
| 3.2, 4.1 | инцидент → гипотезы → PROSPER → GAP → рекомендация без вмешательства |
| 4.2 | раздел 6 витрины: выбор инструмента агентом и причина |
| 5.1 | «Утвердить / Вернуть на доработку / Отклонить» |
| 5.3 | остановка по потолку: строка в очереди, агент стоит до «Разобрано» |
| 6.2 | раскрытый журнал запусков: модель, токены, вызовы, время, ошибки |

LLM — локальная GPT-OSS 120B на сервере LM Studio (облако запрещено). Такт с инцидентом идёт 17–25 мин: в ролике эти участки ускорить или вырезать, оставив начало и конец.

## Подготовка (до записи, не в кадре)

1. **PetEx свободен:** закрыть свои окна PROSPER и GAP.
2. **LM Studio:** на сервере загружена `openai/gpt-oss-120b`, сервер запущен. Проверка из окна PowerShell:
   ```powershell
   (Invoke-RestMethod http://10.9.0.88:1234/v1/models).data.id
   ```
   В списке должна быть `openai/gpt-oss-120b`. На сервере в это время не должно идти других задач.
3. **Битрикс24 во втором окне:** браузер, «Задачи» → «Делаю», фильтр по себе. Окно поставить рядом с витриной или держать вкладку открытой.
4. **Потолки — рабочие:** в `config/cycle_limits.json` `"max_llm_calls_per_day": 20`.
5. Начать сутки заново с живым расчётом и открыть витрину:
   ```powershell
   cd C:\work-scripts\First_AI_agent
   C:\work-scripts\venv\Scripts\python.exe tools\run_agent.py --reset --fresh
   .\start_dashboard.bat
   ```
   http://127.0.0.1:8503/ — «Агент ещё не обработал ни одного часа».
6. Если сегодня уже были прогоны и бюджет израсходован — сброс решением инженера (записывается с причиной):
   ```powershell
   C:\work-scripts\venv\Scripts\python.exe tools\run_agent.py --reset-budget "запись скринкаста v2"
   ```

Команды окна 2 по порядку:
```powershell
cd C:\work-scripts\First_AI_agent
Remove-Item Env:AGENT_LLM -ErrorAction SilentlyContinue   # модель по умолчанию — config/llm_policy.json (GPT-OSS 120B)
C:\work-scripts\venv\Scripts\python.exe tools\run_agent.py --loop --interval 10 --stop-at 6
C:\work-scripts\venv\Scripts\python.exe tools\run_agent.py --loop --interval 10 --stop-at 17
C:\work-scripts\venv\Scripts\python.exe tools\run_agent.py --loop --interval 10 --stop-at 19
```

**LLM недетерминирована:** порядок гипотез, выбор инструмента и остаток могут отличаться от паспорта. Говорить то, что видно на экране.

**Если в 18:00 у W50 нет изменений и пересчёта нет**, потолок не сработает (без новых данных LLM не вызывается). Тогда перед 18:00 нажать «Вернуть на доработку» с комментарием по инциденту 15:00 — полный пересчёт вызовет LLM и упрётся в потолок.
